# bg3-builds

# Проєкт: Сайт для білдів Baldur's Gate 3 (BG3)

## Мета

Особистий пет-проєкт для практики. Без зайвих складнощів та важких фреймворків.

## Стек технологій

- **Frontend:** Vanilla JS (чистий JS), HTML, CSS.
- **Backend:** Простий REST API на Node.js + Express (пишу сам).
- **База даних:** MongoDB (вже є).

## Дизайн та структура сторінки

Дві основні таблиці/блоки, розташовані поруч:

1. **Лівий блок (Основа):** назва білду, загальний опис, найкращі раси, таблиця характеристик (СИЛ, СПР, ВИТ, ІНТ, МУД, ХАР).
2. **Правий блок (Екіпірування):** 3 розділи по предметах (Акт 1, Акт 2, Акт 3).

- Можливість перемикатися між білдами та додавати нові через форму прямо на сайті.

## План розробки (покроково)

- [ ] **Крок 1:** Верстка HTML/CSS двох колонок поруч (статичний макет).
